3. SOLO PRACTICE QUIZ MODE (/quiz/single)
--------------------------------------------------------------------------------
- Multi-Course Support: Comprehensive questions for HTML5, CSS3, and JavaScript
- Multi-Topic Selection: Choose one or multiple topics with search and select-all
- Strict Topic Isolation: Questions ONLY come from topics selected by the user;
  no unrelated questions are ever backfilled from other topics
- 150+ Deep Question Bank: Diverse Easy, Medium, and Hard curated questions
- Multi-Tier Difficulty Balancing: Automatic distribution (~30% Easy, ~40% Medium, ~30% Hard)
- Anti-Repetition Engine: Detects questions recently answered by the student
  and prioritizes fresh, unseen questions
- Direct Option Evaluation:
  * Selecting an option instantly checks correctness
  * Correct option turns Emerald Green (#10B981) with check icon
  * Incorrect option turns Crimson Red (#EF4444) with cross icon, and
    reveals the correct answer in green
- Instant Educational Explanation: Real-time card explaining why an answer is
  correct or incorrect
- Randomized Option Distribution (A, B, C, D):
  * Options are deterministically shuffled per attempt
  * Correct answer is evenly distributed across A, B, C, and D (~25% each)
  * Option A is never statically fixed as the correct answer
- Smooth Auto-Advance:
  * Advances to next question after 1.2s on correct answers
  * Advances after 2.2s on incorrect answers (giving time to read explanations)
  * Student can click "Next Question" anytime to advance instantly
- Spaced Repetition Reinforcement: Questions answered incorrectly are
  automatically re-queued 2-3 questions ahead until the student masters them
- Server-Side Countdown Timer with automatic timeout submission


4. MULTIPLAYER TOURNAMENT ARENA (/room/[roomCode] & /live/[quizId])
--------------------------------------------------------------------------------
- 6-Digit Room PIN & QR Code generation for instant student access
- Live Waiting Room Lobby: Shows joined participants in real time with avatars
- High-Concurrency Scalability (100–1000 Students):
  * Instant room start broadcast via Socket.IO (zero database strain)
  * Lightweight indexed quick status endpoint (?quick=1)
  * Jittered fallback polling (5–8s randomized) preventing server crash spikes
- Anti-Screen Peeking Randomization:
  * Each student in the same room receives a different question sequence
  * Each student receives different option positions (A, B, C, D)
  * Students sitting side-by-side cannot copy answers from neighboring screens
- Real-Time Anti-Cheat Monitor:
  * Tracks browser tab switches (visibilitychange) and window defocus (blur)
  * Displays warning alert to the student: "Tab switch detected!"
  * Emits live violation counter to the room socket
- Room Creator Host Controls (Anti-Cheat Disqualification):
  * Host live dashboard displays real-time cheat violations (e.g. "⚠️ 2 Tab Switches")
  * Host has an instant "Close Tab / Kick" button next to cheating students
  * Clicking immediately disqualifies the student and broadcasts tab termination
  * Cheating student's screen locks into a red termination screen:
    "SESSION TERMINATED: Disqualified by Room Host for Academic Dishonesty"
- Live Tournament Dashboard & Leaderboard (/live/[quizId]/dashboard):
  * Deterministic real-time ranking: Score -> Accuracy -> Time Taken
  * Visual podium for 1st, 2nd, and 3rd place with celebration confetti
